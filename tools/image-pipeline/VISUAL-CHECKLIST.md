# 视觉抽查清单（图片管线转换后必做）

转换参数（限宽、质量）是否可接受，以本清单的人眼抽查为准，不只看字节数。
抽查方式：`npm run preview` 后用浏览器打开文章页，对照 `assets/img-src/` 原图逐项核对。
发现任一项不达标 → 调高 `--quality` 或 `--max-width` 重跑，并在 pilot 报告中记录。

## 通用项（每张图）

- [ ] 与源母版并排放置对比：无可见糊化、色块、振铃（WebP 低质量时边缘出现光晕）
- [ ] 渐变/天空/纯色区域无带状条纹（banding）
- [ ] 细线（坐标轴、表格线、框线）不断裂、不发虚
- [ ] 页面实际渲染宽度（正文容器 ≤760px）下清晰；200% 缩放页面仍可接受
- [ ] 深色/浅色两个主题下边框与阴影表现正常（站点有 `.article-body img` 边框样式）

## 论文图表专项（文字可读性）

- [ ] **表格截图**（table01–table08）：表内数字、± 号、小数点、上下标在 760px
      渲染宽度下可逐一辨认；表头加粗与普通行可区分
- [ ] **带坐标轴的图**：轴标签、刻度数字、图例文字可读
- [ ] **流程图/管线图**（fig02）：方框内文字、箭头标注可读
- [ ] **场景图/标注图**（fig10）：Set-of-Mark 的数字标签、对象类别文字可读
- [ ] **对比图**（fig07）：不同方法列之间能分辨纹理差异，无压缩噪声掩盖细节

## 布局与加载行为

- [ ] 首屏只加载第一张内容图（eager），滚动时下方的图才发起请求（lazy 生效）
- [ ] 图片加载前后页面不跳动（width/height 已注入，CLS ≈ 0）
- [ ] 第一张内容图带 `fetchpriority="high"`，其余图不抢首屏带宽
